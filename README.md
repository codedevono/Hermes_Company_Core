# 🚀 Hermes Company Core

The central orchestration system for the Hermes AI companion.

## 🛠️ Infrastructure
- **Core Server**: FastAPI + OpenAI Whisper (Small) for Voice-to-Text.
- **Voice Output**: Microsoft Edge-TTS (Bilingual Indian English/Hindi).
- **Interface**: Manual Mic Bridge for PC-to-Server communication.

## ⚡ Quick Start
1. Run `setup_jarvis_env.ps1` to build the brain.
2. Run `init_hermes.ps1` to wake up the server.
3. Run `start_mic_manual.ps1` to start talking.

## 🎮 Management
Use `hermes_manage.ps1` for a one-tap menu to Wake Up, Sleep, or Rebuild the system.
